# وسيط قصاصة للمسح السحابي

شغّل `server.mjs` باستخدام Node.js 22 أو أحدث. عيّن `OCR_SPACE_API_KEY` من مدير الأسرار في الاستضافة. يعرض الخادم المسار `POST /v1/scan` خلف وكيل HTTPS، ويتلقى صورة PNG ويعيد النص بصيغة JSON. لا يكتب الصور أو النصوص إلى القرص. مع الوضع التلقائي تُرسل الصورة المحددة لهذا الوسيط ثم إلى OCR.space عند توفر الاتصال.

اضبط `PORT` و`BIND_ADDRESS` حسب الاستضافة. اضبط `OCR_DAILY_LIMIT` بما يناسب حصة الخدمة. الحد داخل الوسيط يُحسب لكل عملية خادم. استخدم حدًا مشتركًا في الوكيل عند تشغيل عدة نسخ، واضبط حد الطلبات حسب عنوان العميل في وكيل HTTPS. لا تعتمد سرية المفتاح على إخفاء عنوان الوسيط.

بعد نشر الوسيط، مرر عنوان HTTPS الكامل المنتهي بـ `/v1/scan` إلى وسيط `-OcrRelayUrl` عند تشغيل `Build-Setup.ps1`. يتضمن المثبّت عنوان الوسيط فقط. عند غياب العنوان يعتمد المثبّت على الإعداد المحلي الموجود على الجهاز أو يعود الوضع التلقائي إلى المسح المحلي.
